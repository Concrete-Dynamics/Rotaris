# 12 — Service Classification

> Perspective: What pattern each module or subsystem follows — its category and
> primary responsibility.
> Diagram type: Table

---

| Module                                 | Classification                   | Primary Pattern                                | Notes                                                                                                                                                                                 |
| -------------------------------------- | -------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | -------------------------------- | ------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cli/app.py`                           | **Entrypoint**                   | Command router                                 | Typer CLI; routes interactive vs. headless                                                                                                                                            |
| `cli/argparse_app.py`                  | **Entrypoint**                   | Command router                                 | Argparse; headless-only, avoids importing `tui/`                                                                                                                                      |
| `tui/`                                 | **UI layer**                     | Reactive TUI                                   | Textual `App`; pushes updates via widget messages                                                                                                                                     |
| `ralph/loop.py`                        | **Loop driver**                  | Bounded iteration                              | Runs one top-level todo task per iteration; delegated children can fan out concurrently inside the scheduler                                                                          |
| `orchestrator/scheduler.py`            | **Scheduler façade**             | Public orchestration seam                      | Stable `Scheduler` interface for Ralph Loop callers; delegates child execution, drain/resume, compression, transcript, and report policy to deeper modules                            |
| `orchestrator/child_run.py`            | **Child execution loop**         | Request-shaped run module                      | Owns one child `LocalConversation` run: callbacks, tool timing, steering injection, watchdog use, retries, fallbacks, todo correction, and report handoff                             |
| `orchestrator/scheduler_drain.py`      | **Delegation drain**             | Foreground/background drain                    | Spawns ready children, waits for terminal updates, injects background notifications, and resumes parent conversations with recovery                                                   |
| `orchestrator/child_manager.py`        | **DAG manager + slot scheduler** | Dependency graph + per-model concurrency queue | DFS cycle detection, depth/total/active child caps, `enqueue_model_slot()`, `_release_model_slot_locked()`                                                                            |
| `orchestrator/transcript_progress.py`  | **Progress assessor**            | Transcript classifier                          | Extracts transcript events and classifies outcomes (`executed_work`, `message_only`, etc.)                                                                                            |
| `orchestrator/child_report_builder.py` | **Report policy layer**          | Diagnostic passthrough                         | Builds terminal & recovery reports; normalizes misclassifications. `_validate_child_report` records diagnostics only — completion decisions moved to `ralph/completion_classifier.py` | \n  | `ralph/completion_classifier.py` | **Completion gate** | Single-shot small-LLM call | Classifies each succeeded iteration as COMPLETE / NEEDS_ITERATION / UNCLEAR using `small_model`; replaces keyword-based `_validate_child_report` downgrades and deprecated `IntentValidator` |
| `orchestrator/artifacts.py`            | **Artifact store**               | Session store                                  | Child reports and authored artifacts shared across sibling agents and resumes                                                                                                         |
| `orchestrator/summary_agent.py`        | **Report generator**             | Single-shot LLM call                           | Converts transcript → `ChildReportArtifact`; retries once; **skipped** when child published an authored artifact                                                                      |
| `agents/factory.py`                    | **Factory registry**             | Factory-pattern                                | Returns factories (not instances); closure-captures deps                                                                                                                              |
| `tools/`                               | **Tool library**                 | Command objects                                | Each tool: `ToolDefinition` + `ToolExecutor`                                                                                                                                          |
| `haet/`                                | **File editor**                  | Opt-in hash-anchored                           | Alternative to `read_file`/`write_file`; snapshot integrity                                                                                                                           |
| `config/loader.py`                     | **Config layer**                 | Layered merge                                  | defaults → discovered MCP → provider snapshot → global → workspace; field-wise overlay                                                                                                |
| `config/secrets.py`                    | **Secret manager**               | Env-var injection                              | Per-server MCP secrets; CRUD over `secrets.yaml`                                                                                                                                      |
| `auth/`                                | **Auth broker**                  | OAuth/API-key flows                            | Rotaris Cloud, Device Flow (Copilot), PKCE (Codex), API-key providers                                                                                                                  |
| `auth/provider_settings.py`            | **Provider settings service**    | Token-backed settings mutation                 | CLI/TUI provider key/base-URL editing and validation; writes keys through `TokenStorage`                                                                                              |
| `providers/`                           | **Catalog**                      | Registry + discovery                           | Built-in providers, OpenAI-compatible instances, model limits, tier defaults                                                                                                          |
| `models/`                              | **Model metadata**               | Thinking-control catalog                       | Provider/model-specific reasoning-control lookup used during model setup                                                                                                              |
| `session/persistence.py`               | **Persistence**                  | Atomic split state                             | Split state/evidence layout; PID-based locking; reads a pre-2026-08-23 `snapshot.json` when `state/` is absent (SWR-1550) and writes none                                             |
| `session/diagnostics.py`               | **Observability**                | Evidence writer                                | Timeline, issues, model input, tool-call (args/result on error), context-selection, report-validation logs; `run_config.json` includes `resolved_system_prompt`                       |
| `session/state_repair.py`              | **Repair**                       | Post-deserialization patch                     | One-shot repair of missing `reasoning_content` on event files at session-open time; runs only for models requiring echo-back (e.g. DeepSeek V4)                                       |
| `tracking/`                            | **Observability**                | Counter accumulator                            | Per-agent token + tool-call tallies; no cost computation                                                                                                                              |
| `api/prompts.py`                       | **API surface**                  | Submit-only                                    | Programmatic prompt injection into running session                                                                                                                                    |
| `core/`                                | **Shared types**                 | Plain value types                              | `PromptRegistry`, prompt enums — no domain logic                                                                                                                                      |
| `model_input.py`                       | **Sanitization**                 | Decorator pipeline                             | Stale drop, error redaction, progressive truncation, reasoning_content echo-back injection on every LLM completion; serialization validation is sampled                               |
| `improvement/`                         | **Post-run analysis**            | Approval pipeline                              | Non-blocking collector writes improvement proposals; improver runs only after approval                                                                                                |
| `mcp/`                                 | **Import shim**                  | Namespace guard                                | Prevents `rotaris_core.mcp` shadowing external `mcp` package                                                                                                                             |
