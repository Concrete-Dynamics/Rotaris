# `composer-proof`

What this proof measures and re-verifies. The [proof registry](README.md) carries its area, prerequisites,
platforms, flags and neighbours; the script is [`apps/desktop/scripts/composer-proof.mjs`](../../apps/desktop/scripts/composer-proof.mjs).

The composer's chips, drafts, history recall and run header, and (launch 4b, `stop-run`, since 2026-10-13) the composer's own Stop run pressed: "Cancelling…" and "Force stop" while the graceful stop waits, held across a permission-mode change (OQ-165, REQ-SESSION-186; red with `Run.stopAccepted`'s hold removed)
