The primary action control — one filled primary per screen, everything else outline or ghost.

```jsx
<Button variant="primary" icon="ph-plus">New session</Button>
<Button variant="secondary">Sessions</Button>
<Button variant="danger" size="compact">Cancel</Button>
```

Variants: `primary` (filled accent), `secondary` (outline), `ghost` (text only), `danger`, `warning`, `link`. `size="compact"` for dense toolbars. Disabled state drops to 45% opacity.
