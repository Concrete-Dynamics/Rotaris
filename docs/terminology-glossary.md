# Rotaris Terminology Glossary

This glossary defines domain terms used in the Rotaris codebase. It favors the
local meaning of each term over generic industry definitions, and each entry links
to one or two places where the term is implemented or used. User-interface terms
refer to the **Rotaris desktop app** (PySide6, `apps/rotaris/src/rotaris/`) — the
primary interface; the Textual TUI's vocabulary is not covered here.
