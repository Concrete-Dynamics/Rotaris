we would like to shift the branding towards "Rotaris" as the name of the harness framework. We want a modern, yet "mathematical flair" (but not too much) and precise UI.

The goal is an electron app which will replace the terminal ui we currently have. In the end this should be kind of like a workspace. Multiple windows (for i.e. sub agent type receives an own window, and each subagent instance receives a tab within that window). we need a treeview as an overview that displays the depth and currently running agents. also respect the application of skills, prompts, mcps and so on. we want to have shortcuts but not primarily over shortcuts like claude code and codex do it, instead we want to make use of the power of UI in desktop. i.e. clicking on an agent and setting the model and reasoning strength via dropdowns instead of /model. the dashboard should give an overview of the most imposant and interesting informations right away, like token usage, subscription limits, current context windows of each agent, and what they currently use as tools. also we want git first, so we see on what branch we are and git history. and something like a worktree where different sessions work on different branches simultaneously. we also want a possibility to swap the delegation strategy, for instance swapping between swarm of agents, centralized orchestrator or single agent. also, dont miss any features currently available in the github repo "Rotaris" which is our codebase. take a look at the current implementation of the terminal UI and UX features there, so you dont miss anything in the prototype.

design:
the design should reflect the branding around "Rotaris". minimalisic, yet information rich and vibrant accent colors where applicable. we want to distinct ourselves from the terminal ui framworks and want to offer a more user friendly and modern / professional way of interacting with agents.

keep in mind that this is not a webpage but an electron desktop application.
