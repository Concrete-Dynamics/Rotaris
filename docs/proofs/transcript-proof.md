# `transcript-proof`

What this proof measures and re-verifies. The [proof registry](README.md) carries its area, prerequisites,
platforms, flags and neighbours; the script is [`apps/desktop/scripts/transcript-proof.mjs`](../../apps/desktop/scripts/transcript-proof.mjs).

The projection, the caches, the empty state (ADR-0045/0046), and REQ-CHAT-055's append comparison — alternating launches pooled to thirty a side, in frames and milliseconds with their spread, plus one traced launch of each fixture read back by `lib/trace-summary.mjs`, which since 2026-09-29 also carries V8's CPU profile: `append.json`'s `profile` names the script per increment by function and by source module, loaded minus empty; stage 3b also expands the planted activity line and reads the twelve frames after the click, opens a planted user row's image attachment (a growth under an unchanged measurement key) and reads the twelve painted frames after it, and holds a pair of rows already drawn to 1 px (2026-10-01); stage 3c (`capacity`, 2026-10-01) resizes the window to 1440x4300 over 400 one-line notices and holds every row on screen bound — Xvfb with no window manager does not clamp the window, so the standard `-screen 0 1600x1000x24` asks it, and a host that clamps the window records the stage NOT ASKED in the verdict; stage 3d (`interleave`, 2026-10-06) runs two scripted children that each hold a terminal command open while the other appends, so rows settle below later rows, and holds the renderer's replica to every row the store recorded (REQ-MONITOR-214); since 2026-10-14 the behaviour stage also opens the search panel from the transcript toolbar's search control and closes it by window-level Escape pressed on its Next button, reading the composer focused (`behaviour.searchControl`, REQ-CHAT-074, REQ-SHELL-055); `--only=<stages>` runs named stages after the `empty` launch; since 2026-10-02 a run fails when any launch's log carries Chromium's "ResizeObserver loop" line (`results.resizeObserverLoops`, ADR-0045)
