# `terminal-stream-proof`

What this proof measures and re-verifies. The [proof registry](README.md) carries its area, prerequisites,
platforms, flags and neighbours; the script is [`apps/desktop/scripts/terminal-stream-proof.mjs`](../../apps/desktop/scripts/terminal-stream-proof.mjs).

The stream in the run host against a **real PTY** (ADR-0021), each command spelled in the host's shell: PowerShell on Windows, the POSIX shell elsewhere (REQ-TOOLS-104). Before 2026-09-28 it spoke PowerShell everywhere and measured nothing off Windows (`docs/defects/fixed/terminal-stream-proofs-real-pty-half-speaks-powershell-to-a-posix-shell.md`). Since 2026-09-29 the deltas carry what the command wrote and no marker (`deltasCarryOnlyTheCommand`, live-run L9), and a second command on the same stream starts on its own row of the renderer's display (`reopenedStreamStartsOnAFreshRow`); since 2026-10-15 its `--packaged` section (`terminal-proof/packaged.mjs`) drives only what a packaged build keeps — a loopback stub model through the shipped client, the probe's three variables, REQ-SHELL-109's auto-open line in main's log as the surface reading — and `node apps/desktop/scripts/terminal-proof/packaged.mjs --app=<out/main/index.js>` runs it under Electron against a seam-free `ROTARIS_BUILD=package` bundle, refusing one the seam check fails (`docs/defects/fixed/terminal-proofs-packaged-launch-drives-seams-a-packaged-build-compiles-out.md`)
