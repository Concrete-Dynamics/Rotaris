# `code-intel-proof`

What this proof measures and re-verifies. The [proof registry](README.md) carries its area, prerequisites,
platforms, flags and neighbours; the script is [`apps/desktop/scripts/code-intel-proof.mjs`](../../apps/desktop/scripts/code-intel-proof.mjs).

The bundled code-intelligence runtime and its manifest (ADR-0035); since fin47 (A4) it asks `bundle.mjs --check` — once it has set the runtime's home aside and wiped its previous evidence, and before it reads the bundle's marker, builds the app or makes any launch (*corrected 2026-10-20: this read "before anything else"*, fin47's review) — and rebuilds a bundle that is absent or stale, streaming the build's output as it runs (since 2026-10-20; fin47 had captured it, so a first build showed no progress and one printing more than 1 MiB would have failed on the buffer), under `--skip-build` too, as `init-proof` and `live-run` check theirs, and `results.json`'s `bundle` names the recipe, pins hash and target the launches ran on and whether the run built it: it used to test the marker's presence alone and ran PD-MCP-004's gate on a superseded runtime (`docs/defects/fixed/code-intel-proof-uses-a-stale-code-intelligence-bundle-without-checking-it.md`); since fin35 (OQ-245) its ninth launch, `child-across`, a delegated tester's whole-project cross-file replacement read back with both files it changed from the child's report and artifact (no language server needed);
