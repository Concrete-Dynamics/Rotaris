# References and Further Lookup

**Review date:** 2026-09-21

This catalog deduplicates the reference links included in the fourteen implementation guides. The links point to primary documentation or original presentations, not third-party summaries. The reference products are examples, not mandatory dependencies.

The guide interfaces, pseudocode, strict invariants, and test tables are proposed implementation contracts. A source citation supports the mechanism identified in the guide, not an assertion that the source implements every proposed safeguard. Provider documentation can change; verify the selected API and runtime versions when implementing. The MCP link deliberately identifies a dated specification.
