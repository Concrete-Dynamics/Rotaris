text-secondary — default: icons inherit text, no color of their own
text-tertiary — passive metadata beside dim caption text
accent-400 — skills & capabilities, the brand's own objects
info-500 — tool invocations, matching mono tool names in logs
run / ok — live activity or healthy connection
wait / warn — blocked on input, or nearing a limit
fail / danger — failures and destructive actions only
done — completed lifecycle state (marine, same as accent)
One colored icon per row at most. Never color an icon decoratively — if it isn't one of these meanings, it stays neutral.
